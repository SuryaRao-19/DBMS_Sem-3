Privacy & Data Handling Policy

EZ Charge Network Portal — Independent Academic Demonstration (EV ChargeNet)
Independent Academic Demonstration Notice: This portal is an educational database & software engineering project modeled on publicly available Tata Power EZ Charge reference information. It is not affiliated with, endorsed by, or operated by The Tata Power Company Limited.

1. Information Collection

We collect only the minimum information required to demonstrate EV charging workflows: account profile details when you register, vehicle specifications you enter, simulated booking and session logs, optional support enquiries submitted through the contact form, and server-side audit/QR scan counters.

2. Account Information

Registered EV Owners provide their full name, email address, optional phone number, and password. Public self-registration strictly assigns the OWNER role; administrative accounts can only be provisioned by an existing administrator. Passwords are never stored in plaintext.

3. Booking & Charging Simulation Information

Vehicle registration details, charger dispenser selections, slot timestamps, and simulated energy metering (kWh) are stored in the project database solely to demonstrate conflict detection, pricing calculation, and demonstration receipt generation. No real EV chargers are controlled or monitored.

4. Payment Demonstration Information

All checkout flows operate exclusively in Razorpay TEST MODE ONLY or local HMAC-SHA256 sandbox mode (live merchant keys rzp_live_* are blocked at runtime). We never collect or store real bank card numbers, CVVs, or real UPI PINs; stored ledger fields contain only test order/payment IDs, dynamic test QR tokens, expiry timestamps, and simulated INR/GST breakdown amounts.

5. Contact Form Information

Messages submitted on Contact Us (name, email, optional phone, subject, category, message) along with request IP metadata used for rate limiting and spam prevention are validated by the Flask backend, archived in MySQL (ContactMessages), and optionally forwarded via server-configured Web3Forms credentials.

6. Data Storage

Portal records reside in a relational MySQL 8.0+ InnoDB database. Seeded demonstration accounts (@example.test) and live user-submitted records are tracked distinctly via origin/demo indicators.

7. Data Security

Security controls include Werkzeug password hashing (scrypt), parameterized SQL queries, global CSRF token enforcement, per-request account status verification, strict ownership checks (IDOR prevention), HttpOnly / SameSite=Lax session cookies (with Secure cookies and disabled debug mode in production), and server-side HMAC-SHA256 verification on payment callbacks.

8. Third-Party Services

Depending on deployment environment configuration, the platform may connect to: Google Maps JavaScript API (or fallback Leaflet.js / OpenStreetMap tiles) for verified coordinate mapping, Razorpay Test APIs for test-mode checkout/QR payloads, and Web3Forms for backend enquiry delivery. Links to official Tata Power web pages and mobile app listings open externally under Tata Power's own terms and policies.

9. User Rights

Authenticated users may review and update their profile details and password in Profile Settings, manage or remove registered demonstration vehicles, cancel eligible upcoming bookings, and request account deactivation or enquiry deletion from a system administrator.

10. Contact Information

For questions about this academic demonstration portal or test dataset handling, submit an enquiry through our Contact Us page or review the Data Source Register. For official Tata Power EZ Charge commercial customer service, refer directly to Tata Power's published support channels (1800 833 2233 / evsupport@tatapower.com).
